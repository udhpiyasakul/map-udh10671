# Udon Thani Hospital Interactive 3D Digital Twin Web App
### ระบบแบบจำลองดิจิทัลแฝด 3 มิติเชิงโต้ตอบสำหรับโรงพยาบาลอุดรธานี (Smart Hospital Operations Center)

---

## 1. บทนำและวัตถุประสงค์ (Overview)

**Udon Thani Hospital Interactive 3D Digital Twin** คือเว็บแอปพลิเคชันศูนย์ปฏิบัติการอัจฉริยะ (Operations Center) ที่จำลองภูมิทัศน์และอาคารบริการของโรงพยาบาลอุดรธานีในรูปแบบ 3 มิติ (WebGL / Three.js) ผสานระบบข้อมูลโทรมาตรจำลอง (Simulated Telemetry Engine) และระบบสารสนเทศภูมิศาสตร์ (GIS Leaflet Map) เพื่อการวางแผนบริหารจัดการพื้นที่ ทรัพยากรเตียง คิวบริการ ยานพาหนะฉุกเฉิน และเครื่องมือแพทย์ระดับตติยภูมิ

> ⚠️ **ข้อกำหนดด้านข้อมูลและความปลอดภัย (CRITICAL PRIVACY NOTICE):**
> **ข้อมูลทั้งหมดในระบบนี้เป็นข้อมูลจำลอง (SIMULATED DATA)** จัดทำขึ้นเพื่อการสาธิตทางวิศวกรรมซอฟต์แวร์และการวางแผนเชิงพื้นที่ **ห้ามนำเสนอหรือถือว่าเป็นข้อมูลผู้ป่วยจริง ข้อมูลบุคลากรจริง หรือข้อมูลการปฏิบัติงานจริง** ระบบไม่มีการเชื่อมต่อกับระบบเวชระเบียน (EHR/HIS) และไม่มีการควบคุมเครื่องมือแพทย์หรือระบบอาคารจริงใด ๆ

## 2. ฟังก์ชันการทำงานหลัก (Core Features)

### A. 3D Hospital Viewport & Scene Architecture (โครงสร้างอาคารจริง รพ.อุดรธานี จาก UDHMapIndoor)
- **ฉากโรงพยาบาล 3D จำลองสมจริงตามผังจริง:**
  - **อาคารหลวงตาพระมหาบัว ญาณสัมปันโน (10 ชั้น)**: หอผู้ป่วยในหลัก พระสงฆ์อาพาธ ศูนย์มะเร็งและโรคเลือด มีสถานีรถไฟฟ้ารับส่งผู้ป่วยและนิทรรศการชั้น 1
  - **อาคารผู้ป่วยนอก (OPD 9 ชั้น)**: โถงคัดกรองแรกรับ (Screening), เวชระเบียน (Reception), ห้องยาอัตโนมัติ (Pharmacy), ห้องเจาะเลือดแล็บ (Lab), และโถงลิฟต์โดยสารหลัก
  - **อาคารเฉลิมพระเกียรติฯ (ศูนย์อุบัติเหตุฉุกเฉิน 8 ชั้น)**: ศูนย์อุบัติเหตุฉุกเฉินระดับตติยภูมิ, Trauma ICU, ห้องผ่าตัดฉุกเฉิน, ศูนย์รังสี CT/MRI, และลานจอดเฮลิคอปเตอร์ดาดฟ้า
  - **อาคารศูนย์เชี่ยวชาญด้านมะเร็งครบวงจรและห้องผ่าตัด (10 ชั้น)**: ศูนย์สวนหัวใจระนาบคู่ (Cath Lab), เคมีบำบัด, รังสีรักษา, และ 16 ห้องผ่าตัดปลอดเชื้อ
  - **อาคารสนับสนุนบริการและโลจิสติกส์การแพทย์ (10 ชั้น)**: ศูนย์จ่ายกลาง (CSSD), คลังยา, โภชนาการ, และสถานีชาร์จหุ่นยนต์ AGV
  - **อาคารอำนวยการ (4 ชั้น)**: สำนักงานผู้อำนวยการและงานยุทธศาสตร์
  - **อาคารจอดรถฉุกเฉินและศูนย์กู้ชีพ 1669 (Ambulance Bay)**: แท่นจอดเทียบรถพยาบาล ALS ทางเชื่อมด่วนสู่ ER
  - **ทางเดินเชื่อมต่ออาคาร (Campus Walkways & Skywalks)**: สะพานทางเชื่อมลอยฟ้าเชื่อมต่ออาคาร OPD, อาคารเฉลิมพระเกียรติฯ, อาคารหลวงตาฯ และอาคารศูนย์มะเร็ง
- **ระบบแผนผังความหนาแน่น (Utilization Heatmap Layer):**
  - แสดงเฉดสีอัตราการใช้พื้นที่: เขียว (< 60%), ฟ้า/น้ำเงิน (60–75%), ส้ม (75–88%), แดง (> 88%)
- **การตัดมุมมองเฉพาะชั้น (Floor Cutaway View):**
  - แสดงเฉพาะชั้นที่เลือก (เช่น F1, F2, F3, F4, F5, F7) เพื่อตรวจสอบโครงสร้างภายในและตำแหน่งห้องตามผัง `opd_floorplan.geojson`

### B. Camera & Navigation Controls
- **Orbit, Pan & Zoom:** รองรับ Mouse, Keyboard และ Touch gestures บนมือถือ/แท็บเล็ต
- **Overview:** กลับสู่มุมมองภาพรวมทั้งวิทยาเขต
- **Rotate 360°:** หมุนชมพื้นที่อัตโนมัติแบบพาโนรามา
- **Flythrough Inspection Tour:** เคลื่อนกล้องอัตโนมัติตามเส้นทางลาดตระเวนรอบโรงพยาบาล
- **Building Focus & Object Tracking:** เมื่อคลิกที่อาคาร ห้อง อุปกรณ์ หรือยานพาหนะ กล้องจะซูมและโฟกัสอัตโนมัติ

### C. Simulation Engine (ระบบจำลองการทำงาน)
- **การเคลื่อนที่ของยานพาหนะตามเส้นทาง (Waypoint Navigation):**
  - รถพยาบาลฉุกเฉิน ALS 1669 พร้อมสัญญาณไฟไซเรนฉุกเฉิน
  - หุ่นยนต์ขนส่งอัตโนมัติ AGV สำหรับเวชภัณฑ์ปลอดเชื้อและยา
  - รถบริการรับส่งผู้รับบริการภายในพื้นที่ (Patient Shuttle)
- **การปรับความเร็วเวลา:** ปรับได้ `1x`, `3x`, `8x` พร้อมปุ่ม `Pause` และ `Resume`
- **การจำลองคิวและเวลารอคอย:** ปรับเปลี่ยนค่าแบบไดนามิกตามช่วงเวลาอย่างสมจริง

### D. Real-time KPI Dashboard
1. จำนวนแผนกที่เปิดให้บริการ (12/12 แผนก)
2. จำนวนห้อง/เตียงที่พร้อมใช้งาน
3. จำนวนห้องที่มีผู้ใช้งาน
4. อัตราการใช้พื้นที่โดยรวม (%)
5. จำนวนผู้รับบริการรวมแบบไม่ระบุตัวบุคคล (Simulated Aggregate Patients)
6. ระยะเวลารอคอยเฉลี่ย (นาที)
7. จำนวนคำเตือนระบบและเหตุการณ์วิกฤตที่ยังไม่ปิด
8. อัตราความพร้อมใช้งานของอุปกรณ์การแพทย์สำคัญ (%)

### E. ระบบควบคุมสภาพแวดล้อมและแสง (Lighting & Environment)
- **Preset ช่วงเวลา:** Morning (เช้า), Daytime (กลางวัน), Evening (เย็น), Night (กลางคืน)
- **Fine Sliders:** ทิศทางแสงอาทิตย์ (Azimuth), มุมยก (Elevation), ความเข้มแสง (Intensity), แสงแวดล้อม (Ambient), และ Exposure
- **Emergency Light Preview:** โหมดจำลองไฟฉุกเฉินสำรองและไฟเตือนสีแดง (พร้อมป้ายกำกับชัดเจน)

### F. ระบบสารสนเทศภูมิศาสตร์และผังในร่ม (UDH GIS, Indoor Floorplan & Directory)
1. **GIS Campus Map & Walkways:**
   - พิกัดจริงของโรงพยาบาลอุดรธานี: **17.4087° N, 102.7872° E** (ถนนเพาะนิยม ตำบลหมากแข้ง อำเภอเมือง จังหวัดอุดรธานี)
   - ขอบเขตวิทยาเขต และเส้นโครงข่ายทางเดินเท้าเชื่อมต่ออาคาร (Campus Walkways)
   - หมุดแสดงตำแหน่งอาคารหลัก 7 หลัง พร้อมสถานะเตียงและการเปิดบริการแบบโต้ตอบ
2. **Indoor Floorplan Viewer (ผังอาคารในร่ม UDHMapIndoor):**
   - แสดงผังห้องภายในอาคารผู้ป่วยนอก (OPD) และอาคารหลวงตาพระมหาบัว
   - สลับดูตามชั้น (Level 1 ถึง Level 7) พร้อมตำแหน่งจุดคัดกรอง (Screening), เวชระเบียน (Reception), ห้องจ่ายยา (Pharmacy), ห้องแล็บชันสูตร (Lab), และโถงลิฟต์โดยสาร (Elevators)
   - สามารถคลิกห้องเพื่อสั่งโฟกัสและตัดมุมมอง 3 มิติ (Floor Cutaway View) ทันที
3. **UDH Telephone & Service Directory (สมุดโทรศัพท์และรายนามแผนก):**
   - ค้นหาเบอร์ต่อภายในโรงพยาบาลอุดรธานี (เช่น 1669, 1101, 2101, 2105, 3100)
   - แยกตามหมวดหมู่: ฉุกเฉิน, ผู้ป่วยนอก, ผู้ป่วยใน, ชันสูตรแล็บ, และบริการสนับสนุน
   - ปุ่มเชื่อมโยง "ดูตำแหน่งใน 3D" เลื่อนกล้องไปยังอาคารและชั้นที่ตั้งโดยอัตโนมัติ

### G. ระบบเสียงบรรยากาศจำลอง (Ambient Audio Synthesizer)
- สร้างเสียงสังเคราะห์ด้วย Web Audio API (เสียงระบบหมุนเวียนอากาศ Cleanroom HVAC และสัญญาณเสียงแจ้งเตือนแบบนุ่มนวล)
- ปฏิบัติตามมาตรฐาน Browser Autoplay Policy (เล่นเมื่อผู้ใช้กดเปิดเท่านั้น) พร้อมปุ่มปรับระดับเสียง

### H. คีย์บอร์ดชอร์ตคัต (Keyboard Shortcuts)
- `Space`: หยุด / เล่นการจำลอง (Pause / Resume)
- `1` / `2` / `3`: ปรับความเร็วการจำลอง 1x, 3x, 8x
- `/` หรือ `Ctrl + K`: เปิดหน้าต่างค้นหาด่วน
- `O`: มุมมองภาพรวม (Overview Camera)
- `Esc`: ยกเลิกการเลือก / ปิดหน้าต่างโมดอล

## 3. Technology Stack

- **Frontend Core:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS (Dark Premium Hospital Operations Theme)
- **3D Engine:** Three.js + OrbitControls (Custom High-Performance Canvas)
- **Icons:** Lucide React
- **State Management:** Zustand
- **GIS Mapping:** Leaflet
- **Audio Synthesis:** Web Audio API

## 4. วิธีการติดตั้งและรันโปรเจกต์ (Installation & Running)

### ความต้องการพื้นฐาน
- Node.js 18+ หรือ 20+
- npm หรือ pnpm หรือ yarn

```bash

npm run lint
```

## 6. แนวทางการคุ้มครองข้อมูลและความเป็นส่วนตัว (PDPA Compliance)

1. **ไม่ประมวลผลข้อมูลส่วนบุคคล (Zero PII):** ระบบไม่มีการจัดเก็บ แสดงผล หรือส่งต่อข้อมูลชื่อ นามสกุล เลขบัตรประชาชน หมายเลข HN ที่อยู่ หรือเบอร์โทรศัพท์
2. **การรวมข้อมูลระดับภาพรวม (Aggregation Only):** สถิติทั้งหมดแสดงในรูปจำนวนรวมระดับแผนกและอาคาร
3. **ไม่มีการเชื่อมต่อกับระบบเวชระเบียน (EHR Isolation):** แยกสภาพแวดล้อมออกจากระบบโรงพยาบาลจริงโดยเด็ดขาด

## 7. รายการระบบที่ห้ามควบคุมจากแอปพลิเคชัน (Safety Restrictions)

เพื่อความปลอดภัยสูงสุดตามมาตรฐานความปลอดภัยสารสนเทศทางการแพทย์ ระบบนี้ **ห้ามใช้ควบคุม** ระบบต่อไปนี้โดยเด็ดขาด:
- ❌ ระบบเวชระเบียนผู้ป่วย (EHR / HIS)
- ❌ อุปกรณ์การแพทย์ช่วยชีวิต เช่น เครื่องช่วยหายใจ, เครื่องกระตุกหัวใจ, เครื่องให้สารละลายทางหลอดเลือด
- ❌ ระบบท่อก๊าซทางการแพทย์และออกซิเจนเหลว (Medical Gas & Cryogenic Liquid Oxygen System)
- ❌ ระบบไฟฟ้ากำลังหลักและหม้อแปลงไฟฟ้าแรงสูง
- ❌ ระบบดับเพลิง สปริงเกลอร์ และสัญญาณเตือนอัคคีภัยจริง
- ❌ ระบบรับแจ้งเหตุฉุกเฉินกู้ชีพ 1669 ของจริง
